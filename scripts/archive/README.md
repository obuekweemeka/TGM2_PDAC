# Archived scripts

These scripts produced earlier versions of figures that were later regenerated or
renumbered. They are retained for provenance and should NOT be re-run: several write
figure filenames that, after the renumbering recorded in `final_figure_renumber_v2.R`,
now belong to different figures, so running them would overwrite current outputs.

The scripts in the parent directory produce the figures as they appear in the manuscript.
